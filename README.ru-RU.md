# Загрузчик игр Hoyo

[English](README.md) | [中文](README.zh-CN.md) | Русский

Собрала вот такую штуку для скачивания игр Hoyo. В основном для себя,
но решила, что и здесь её выложить не помешает — мало ли, понадобится
где-то ещё. Пока не доделана, всё ещё вожусь с ней.

Тестировала только на Геншине, да и то не особо глубоко. Остальные
игры, да и вообще много кода, если честно, толком не проверяла. Так
что может сломаться. Ничего конкретного обещать не могу.

Код у меня тоже так себе. Если увидишь что-то странное — скорее всего,
это я.

Если она тебе чем-то пригодится — хорошо, ставь звёздочку. Если что-то
не работает — открывай issue, постараюсь глянуть. Это просто маленькая
штука, которую я сделала для себя, так что без обещаний.

## Требования

Python 3.14 или 3.15. Вот на них и тестировала. На 3.15 одна из
зависимостей может собираться вручную. Про остальные версии не уверена.

## Установка

    pip install -r requirements.txt

## Запуск

    python main.py

При первом запуске попросит выбрать язык.

## Меню

1. Скачать игру
2. Восстановить / обновить игру
3. Просмотр версий
4. Просмотр пакетов
5. Сменить язык
6. Выход

## Примечания

Куда скачивать — выбираешь сам, по умолчанию ./<игра>.
Если остановится на середине — просто запусти ещё раз.
Официальные API могут в любой момент поменяться и всё сломать.

## Известные риски

Может скачаться не та игра, регион или версия.
Найденная версия может не совпадать с той, что ты выбрал.
Не могу обещать, что оно работает или что оно правильное.

## Лицензия

Личное использование. Экспериментальное. На свой риск.
