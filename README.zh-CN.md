# Hoyo 游戏下载器

[English](README.md) | 中文 | [Русский](README.ru-RU.md)

我把这个放在一起为了下载 Hoyo 游戏。它主要是为了我，但是我 figured
我把它扔在这里也以防我需要它在其他某个地方。它还没有被完成，还在
工作它。

只在 Genshin 上真正测试它，并且也不是那么彻底也。其他游戏，以及
诚实的一个很多的代码，我没有实际尝试。所以它可能在你的上面打破。
不能真的承诺任何东西关于它。

我的代码也不是很好也。如果你发现某个东西奇怪的，那可能只是我。

如果它帮助你出来，很好，随意星它。如果某个东西是坏的，打开一个
issue 和我将尝试去看。它是一个小东西我做为了我自己，所以没有承诺。

## 要求

Python 3.14 或 3.15。那是我测试在上面的东西。在 3.15 上一个依赖
可能需要在手上被构建。不确定关于其他版本。

## 安装

    pip install -r requirements.txt

## 运行

    python main.py

它将会问你选择一种语言第一次。

## 菜单

1. 下载游戏
2. 修复 / 更新游戏
3. 查看版本
4. 查看包
5. 改变语言
6. 退出

## 笔记

下载去你想要的任何地方，默认是 ./<游戏>。
如果它停止中途，就再次运行它。
官方 API 可以在任何时间改变和打破这个。

## 已知风险

它可能抓取错误的游戏、地区或版本。
它找到的版本可能不匹配你选择的东西。
不能承诺它工作，或者它是正确的。

个人使用。实验性。在你自己的风险。
